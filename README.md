# Ayni Consciousness Collective

A seven-wing sovereign ecosystem rooted in Calca, Sacred Valley, Perú. This is the public website — a local-first SvelteKit static site.

## Quick start

```sh
npm install
npm run dev      # develop
npm run build    # static build → build/
npm run check    # typecheck
```

## Structure

```
src/
  design/     design tokens — plain CSS custom properties, no framework
  lib/        NavContent · WelcomePanel · scrollDriver
  routes/     the site — one layout, one page
static/       fonts · icons · images
docs/         adr/ (contracts) · design/ (visual reference) · research/
```
